# AUTHORS

NexusMind is maintained by contributors who build, benchmark and review
the engine on their own hardware.

## Maintainers

- RustDesk — founder, architecture, retrieval core

## Contributors

Contributors are listed in `git shortlog -sn` order of first commit.
See the GitHub contributors graph for the full list with avatars.

If you submit a PR that lands, add yourself here in the same PR
(alphabetical by surname) — the project convention is that contributors
list themselves.
