# Support

## Community

- **Discord** — https://discord.gg (real-time help, showcases, office hours)
- **GitHub Discussions** — https://github.com/nexusmind-ai/nexusmind/discussions
- **FAQ** — https://nexusmind.dev/faq (or the in-repo FAQ.md)

## Before asking

- Read the [FAQ](FAQ.md) — it covers GPU memory, Ollama vs vLLM, why Kuzu,
  chunking tuning, and the most common error fixes.
- Search existing issues before opening a new one.
- Include your environment: OS, Python version, Ollama version, model names,
  and the exact command that failed.

## Reporting bugs

Open an issue with the bug template. Include:

- The command you ran
- The full error output (redact anything sensitive)
- Your `config.yaml` (or note that you used defaults)
- Whether the failure reproduces with `docker compose` or from source

## Getting help with contributions

See [CONTRIBUTING.md](CONTRIBUTING.md) — the `good first issue` label is
the recommended starting point.

## Security issues

Do **not** open a public issue. See [SECURITY.md](SECURITY.md).
